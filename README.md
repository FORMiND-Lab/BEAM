# Beyond Greedy Rewriting: State-Aware Beam Search for SCA-Based Multiplier Verification

This repository contains the binary artifact accompanying our DATE 2027 paper.

## Usage

```bash
./beam-verifier --help
./beam-verifier [OPTIONS] <AIG_FILE>
```

The multiplier benchmark and its architecture naming convention are available at [FORMiND-Lab/Multiplier-Benchmark](https://github.com/FORMiND-Lab/Multiplier-Benchmark).
